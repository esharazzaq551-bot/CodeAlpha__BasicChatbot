# CodeAlpha_BasicChatbot

A simple rule-based chatbot built in Python for the
CodeAlpha Python Programming Internship (Task 4).

## What it does
- Replies to: hello/hi, how are you, what is your name, what can you do, thanks, help, bye
- Ignores capital letters and extra spaces
- Keeps running until the user types "bye"

## How to run
1. Install Python.
2. Download codealpha-chatbot.py.
3. Run: python codealpha-chatbot.py

## Concepts used
Functions, loops, if-elif-else, input/output
